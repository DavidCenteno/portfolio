# David Centeno Pedrido — portfolio

Personal site: Next.js 16 · TypeScript · Tailwind v4 · Motion · Lenis. Every route is statically prerendered.

```bash
npm install
npm run dev
```

Deploy: import the repo in Vercel (framework preset: Next.js). Optionally set `NEXT_PUBLIC_SITE_URL`
to the final domain so OG/sitemap URLs are absolute.

Project docs for contributors (and Claude): `CLAUDE.md`, `docs/`.
