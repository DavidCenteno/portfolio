# Build plan

Status legend: `[ ]` todo · `[~]` in progress · `[x]` done

## Architecture (proposed)

| Choice | Why |
|---|---|
| **Next.js 16 (App Router), fully static routes** | David already deploys Next.js on Vercel; every route prerenders (○). Not `output: "export"` — see decision log. |
| **TypeScript + Tailwind CSS v4** | Matches ResuMatch conventions; design tokens as CSS variables. |
| **Motion (framer-motion)** | Declarative scroll/layout animations, reduced-motion support built in. |
| **Lenis** | Smooth scrolling that stays in sync with scroll-driven animations. |
| **Hand-written SVG/Canvas** for the lineage graph | No heavy 3D/graph libs → keeps JS budget small. |
| **next/font** (self-hosted Google fonts) | No layout shift, no third-party font requests. |
| **Vercel** hosting | Same as David's other projects. Analytics: Vercel Analytics (privacy-friendly). |

Content lives in `src/content/*.ts` (typed), generated by hand from `content/profile.md`.

## Page structure

1. **Nav** — name mark, section links, theme toggle, ⌘K hint, "Get in touch".
2. **Hero** — name, one-line positioning, animated lineage graph, CTA (projects / contact / CV).
3. **About** — short narrative + key facts (10+ yrs, BSc Maths, languages, based in ⚠).
4. **Experience** — scroll timeline; Gelato & Barkibu get the most weight; promotions visualised;
   earlier roles collapsed into a compact "earlier" list.
5. **Projects** — ResuMatch, UnDictionary: screenshots, what/why/how, stack, architecture diagram, live link.
6. **Skills** — SQL-query-style grouped skills.
7. **Teaching** — VIU professorship (small section or folded into About).
8. **Contact** — email (copy-to-clipboard), LinkedIn, CV download; footer with build credits.
